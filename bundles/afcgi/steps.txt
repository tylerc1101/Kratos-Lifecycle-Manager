# Infrastructure Setup
[Workflow AFCGI - Full Install]
[Workflow AFCGI - Ground Infrastructure Install]
[Workflow Basekit - Infrastructure Install]
[afcgi bundle] - mgmt-kvm-networking.yml    (Builds bridges on mgmt-kvm)
[afcgi bundle] - stage-repos.yml (include limits option for task template)            (Copies repo files to /opt/openspace/repos on mgmt-kvm)
[basekit bundle] - bootstrap-mgmt-kvm.yml   (Initial setup of mgmt-kvm, installs packages, sets up repos, etc)
[basekit bundle] - prepare-opnsense.yml     (Stages opnsense iso and creates config.xml)
[afcgi bundle] - change-opnsense-settings.yml (AFCGI specific settings for opnsense)
[basekit bundle] - deploy-opnsense.yml      (Deploys opnsense vm on mgmt-kvm)
[basekit bundle] - stage-rhel-image.yml     (Stages rhel qcow2 image on mgmt-kvm)
[basekit bundle] - deploy-vms.yml (include limits option for task template)[limit=mcm] (Deploys MCM VM on mgmt-kvm and configures it)
[basekit bundle] - bootstrap-nodes.yml (include limits option for task template)[limit=mcm] (Deploys NTP and Repo files and sets hostname)
[basekit bundle] - deploy-vms.yml (include limits option for task template)[limit=osms]
[basekit bundle] - bootstrap-nodes.yml (include limits option for task template)[limit=osms]
[basekit bundle] - bootstrap-nodes.yml (include limits option for task template)[limit=osdc]
[End Basekit - Infrastructure Install Workflow (Dont include AFCGI bundle tasks)]
[End AFCGI - Ground Infrastructure Install Workflow]
